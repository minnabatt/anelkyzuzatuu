ГОТОВО ДЛЯ CLOUDFLARE PAGES

1. Репозиторий подключается к Cloudflare Pages.
2. Root directory: anel-final
3. Framework preset: None
4. Build command: exit 0
5. Build output directory: .

TELEGRAM:
Откройте functions/api/telegram.js и замените:
ВСТАВЬ_СЮДА_BOT_TOKEN
ВСТАВЬ_СЮДА_CHAT_ID
на свои данные.

МУЗЫКА:
Положите файл music.mp3 в корень папки anel-final рядом с index.html.

ВАЖНО:
Не меняйте пути /assets/desktop.svg и /assets/mobile.svg.
Функция Telegram находится в functions/api/telegram.js — это правильная структура для Cloudflare Pages Functions.
